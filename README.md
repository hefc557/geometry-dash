# Neon Dash

A browser-playable, original rhythm platformer inspired by the feel of Geometry Dash.

## Play

Open `index.html` in a browser, or enable GitHub Pages for the repository and open the deployed site.

### Controls

- **Space / click** — jump, fly, or wave
- **P** — pause
- **R** — restart
- **1 / 2 / 3** — switch movement modes for testing
- **Practice** — enables automatic checkpoints

## Features

- Cube, ship, and wave movement
- Gravity and mode portals
- Spikes, blocks, walls, jump orbs, and a finish gate
- Three collectible stars
- Attempt counter and progress bar
- Practice mode with checkpoints
- Responsive canvas rendering
- Particle effects, parallax background, grid, screen shake, and UI
- No original Geometry Dash assets, levels, music, or source code are included

## Roadmap

Music sync, an in-browser level editor, custom level storage, more movement modes, user-generated levels, settings, and mobile polish can be layered onto this prototype.
